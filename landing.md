## 🎯 Filosofi Pembelajaran

> **Understand the concept. Build the logic. Write the code. Test the result.**

Setiap modul dirancang dengan pendekatan **Project-Based Learning (PBL)**:
- Konsep dijelaskan lewat analogi nyata
- Kode ditulis berjenjang dari sederhana ke kompleks
- Project nyata di setiap bab untuk memperkuat pemahaman
- Assessment di akhir untuk validasi kompetensi
